# Marke

- **Name:** immer klein geschrieben: *photographics*.
- **Positionierung:** Ebenenbasierter Fotoeditor für Android, gemacht für professionelle Workflows unterwegs.
  (*Layer-based photo editor for Android, designed for professional workflows on the go.*)
- **Logo „Ebenen“:** drei überlagerte Kreise mit 30 / 30 / 62 % Deckkraft; Überlagerungen entstehen nur aus
  der Deckkraft, ohne eigene Farbe. App-Icon hell: Graphit `#1E1E20` auf Weiß `#FAFAFA`.
  - `logo.svg` – App-Icon (Vorlage für GNOME- und iOS-Icons)
  - `logo-mark-white.svg`, `logo-mark-black.svg` – nur das Zeichen, für dunkle bzw. helle Flächen
- **Schriftzug:** „photographics“ in der Schrift der jeweiligen Oberfläche (Android: Roboto über das Material-Theme).
- **Oberfläche:** Material You (Farben vom Hintergrundbild); das Logo in der App nimmt die Theme-Farben an.
  Portierungen nutzen die Gestaltung der jeweiligen Plattform (GNOME/libadwaita, iOS).
- `logo-entwuerfe.html` – frühere Entwürfe (Archiv).
